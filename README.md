# Grewok – Fit For Forever

A premium, modern corporate and e-commerce catalogue website for **Grewok**, an Indian furniture hardware company established in 2015.

## Brand Identity & Aesthetic
* **Tagline**: Fit For Forever | Always Best in Quality
* **Colors**: Deep Navy Blue (`#0A2540`), Accent Red (`#E31C25`), Sleek Whites/Greys
* **Theme**: Minimalist, high-end architectural hardware aesthetic (similar to Blum, Hettich, or Häfele style)

## Tech Stack
* **Backend**: Laravel
* **Frontend**: Tailwind CSS v4.0, Alpine.js, Vite
* **Persistence**: LocalStorage-backed Enquiry Cart

## Key Features
1. **Interactive Product Catalog**: Sortable by category, size, and finish with client-side Alpine.js live search/filtering.
2. **Quote Enquiry Cart**: Add hardware products and specifications to a quote basket, persisting selections across sessions.
3. **Official Success Receipt**: Generates unique invoice reference keys (`GWQ-XXXXXX`) and provides a print-friendly invoice sheet.
4. **Architect & Builder Request**: Contact form integrated for requesting architectural hardware sample packs.
